# HTML 工作流

章节内容与写法见 [讲解规范](teaching-guide.md)。本文件只规定底稿语法、渲染、资源与页面验收。

## 文件与运行时

默认输出 `outputs/<paper-slug>/<paper-slug>.md`、同名 `.html` 与 `assets/`。底稿用相对图片路径，渲染后图片内嵌，原资产保留供修订。脚本相对自身定位，不依赖另两个 skill 或 npm install。

需要 Node.js 20+。PATH 找不到时用宿主运行时发现工具，不硬编码作者电脑路径。

```text
node "<skill-dir>/scripts/render.mjs" "<output-dir>/paper.md"
node "<skill-dir>/scripts/render.mjs" "<output-dir>/paper.md" --out "<output-dir>/paper.html"
```

入口使用 doc / paper / light，关闭 STE 机械句长检查、自动打开和更新。状态隔离在输出旁 `.paper-reading-renderer/`，不修改全局配置。修订底稿后重跑，同路径 HTML 更新，不清理其他输出。

## 底稿语法

主章节用 `##`，小节用 `###`，其他章节必要细分可用 `####`。Method内部只用两个 `###`：“1. 方法概述”和“2. 具体实现”，不再设下级标题。主章节成为目录，三节及以上自动出现目录。保留原主章节编号；入口隐藏自动字母章标与目录字母前缀，锚点保留。

以下片段只演示语法。章节编号、模块名、图片及公式应依据实际论文替换，范围声明只能写已经完成的核验。

## 组件与资源

- 流程：`flow` 默认纵向，简单短链可用 `flow LR`。语法为 `输入 -> 模块: 连线说明`；节点与边标签保持简洁，检查回路与窄屏可读性。
- 表格：标准 Markdown 表格。宽表应在自己的容器横向滚动，不造成全页溢出。
- 时序：先后关系比普通数据流更重要时用 `sequence`。
- 数学：行内 `$...$`；块式公式的 `$$` 各自独占一行。Temml 生成 MathML，资源内嵌，无需 CDN。
- 图片：`![图号与说明](assets/figure.png)`；PNG/JPG/WebP 等，单张不超过 5 MB。使用有效本地资产，不使用远程图片 URL 或空文件。
- 隐藏定位：可用 `<!-- 来源：原文位置 -->` 保存在底稿，不嵌套注释、不生成可见来源栏目。
- 折叠：仅当用户明确需要其他折叠内容时，用完整 `<details>` 与 `<summary>` 标签及空行；不折叠 Method 讲解，不生成来源核对区。

正文不用粗体或 raw HTML 页面布局。更多组件语法可查询：

```text
node "<skill-dir>/scripts/vendor/am.mjs" help flow
```

也可查询 `sequence`、`format`、`image`。帮助为只读命令，不运行上游 config、clean、update、serve 或 video。

## 渲染检查与交付

非零退出时阅读错误并修复底稿后重跑。零退出但存在 math、HTML 或组件警告也须检查，不因文件存在就声称成功。来源不足应如实说明，不能靠渲染补齐。

用可用浏览器在桌面和约 390px 窄屏下检查目录跳转、标题、原图、长公式、流程图、表格、文字和全页溢出；流程图还须看关键节点、标签与箭头是否完整，不能只靠全页宽度检查判定通过。原图可裁成保留标签的子图贴近相关解释，过宽教学图简化主干或拆分支路并说明省略。存在用户要求的折叠内容时再检查展开。结合截图观察实际效果，未做视觉检查时明确说明。

交付 HTML、Markdown 与图片；不删除底稿。HTML 内嵌资源可离线打开，论文等外部链接需联网。页面可能内带底稿，不自动上传、部署或启动长期服务。
